# Khomas Atlas — GitHub Pages edition

Interactive NUST project demo: **synthetic** MSAN traffic, **modelled** population, **provisional** reference positions. Not verified Telecom Namibia infrastructure or real performance data.

## Publish on GitHub Pages

1. Create a **public** repository named `khomas-network-atlas` on GitHub.
2. From the extracted `Khomas_Atlas_GitHub_Pages` folder, upload **index.html**, **assets/**, **data/**, and **.nojekyll** to the repository **root** using **Add file → Upload files**. Do not upload the enclosing folder, and do not upload the ZIP itself.
3. Open repository **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and **Save**.
4. Your site URL will be `https://YOUR-GITHUB-USERNAME.github.io/khomas-network-atlas/`.
5. Refresh after GitHub Pages reports a successful deployment.

Note: GitHub Pages hosts static content; the calculations here run in visitors' browsers using bundled demo data. Internet access is needed for third-party maps and chart libraries. Everything in this public repository, including the source CSV-derived JSON, is publicly accessible.
